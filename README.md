\# Automotive UDS Security Analyzer



Python-based Automotive Cyber Security project for analyzing UDS (Unified Diagnostic Services) communication logs and detecting suspicious diagnostic activities.



\## Project Overview



Automotive ECUs use UDS protocol for diagnostics, maintenance and security operations.



This project analyzes UDS messages, detects security-related events and generates security reports.



\## Features



\- UDS message analysis

\- Diagnostic Session Control detection (0x10)

\- ECU Reset detection (0x11)

\- Read Data By Identifier analysis (0x22)

\- Security Access monitoring (0x27)

\- Brute Force Attack detection

\- UDS log file parsing

\- Security event logging

\- CSV report generation

\- TXT security report generation

\- PDF security report generation



\## Technologies



\- Python 3

\- UDS Protocol concepts

\- Automotive Cyber Security

\- ReportLab

\- CSV Processing
